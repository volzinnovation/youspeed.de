# Reported roadworks advisory, version 1

The fixture is shared by the Swift/Kotlin parsers, cache and relevance tests.
The public contract is
[`MOBIDATA_BW_ROADWORKS_API.openapi.json`](../../docs/MOBIDATA_BW_ROADWORKS_API.openapi.json).
Snapshots are hash-addressed canonical GeoJSON. Native clients validate bounded
bytes, schema, geometry, intervals, provenance and region before cache promotion.
Unknown source clocks/schedules and unsupported meanings never become active
driving cards. Current/previous public caches remain separate from private trips
and contribution identities.

The initially-off feature downloads BW snapshots and evaluates proximity locally
using existing GPS. It sends no location or installation ID. Nearby advisory
presentation is independent of camera signs, speed offers, penalties and capture
triggers. A source report is not visual confirmation of a physical sign or proof
that a roadwork is currently active.

The [implementation record](../../docs/V1_5_IMPLEMENTATION_CONTINUATION_2026-10-23.md)
identifies the prepared sibling backend, local validation and undeployed status.
