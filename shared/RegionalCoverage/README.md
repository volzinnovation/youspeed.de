# Offline regional coverage

Generated by `scripts/map/build_mobile_region_catalog.py` from Geofabrik's public
`index-v1.json` and the mobile bundle targets. Both apps use these polygons for
first-location map selection before any bundle is installed. Never substitute
bounding-box containment for polygon containment.

Source: https://download.geofabrik.de/index-v1.json

Geofabrik GmbH and OpenStreetMap contributors; ODbL 1.0:
https://opendatacommons.org/licenses/odbl/1-0/

These are buffered extract boundaries and can overlap other countries. They
must not independently authorize a national TSR classifier. Source hashes,
attribution, PBF URLs and corresponding `.poly` URLs are retained in the catalog.
See `docs/TSR_COUNTRY_PACK_DELIVERY.md` for regeneration and remaining work.
