# ITSC 2026 Template Pack

Prepared on 2026-02-23 for IEEE ITSC 2026 submissions.

## Included locally

- `starter/itsc2026_main.tex` (IEEE conference starter based on `bare_conf.tex`)
- `starter/IEEEtran.cls`
- `starter/IEEEtran.bst`
- `starter/IEEEabrv.bib`
- `IEEEtran.zip` (full upstream package snapshot)
- `constraints-and-track-fit.md` (submission limits + recommended tracks)

## Official sources

- ITSC 2026 author instructions: <https://ieee-itsc.org/2026/contributions/information-for-authors/>
- ITSC 2026 call for papers: <https://ieee-itsc.org/2026/contributions/call-for-papers/>
- ITSC 2026 accepted invited sessions: <https://ieee-itsc.org/2026/contributions/accepted-invited-sessions/>
- ITSC page links the ITSS Overleaf template (read-only project): <https://www.overleaf.com/read/hkjvkqrgpdrf#e522c1>
- IEEEtran package downloaded from CTAN mirror: <https://mirrors.ctan.org/macros/latex/contrib/IEEEtran.zip>

## Quick start

1. Copy `starter/*` into a new working folder (for example `paper/itsc2026_submission/`).
2. Keep the paper within the ITSC initial limit of 6 pages.
3. Prepare a double-blind submission version for review.
4. Submit via PaperPlaza from the ITSC author page.
