# French pilot repair — 1.1.1 (10014)

Both clients use the same source priority: active user correction, applicable
camera limit, then map data. Ordinary voice and posted camera limits expire after
five minutes, measured from activation rather than the latest GPS fix. A road
reference/name change, confirmed town boundary or applicable restriction end
also clears the relevant assertion. OSM way splits on the same named/referenced
road do not clear it. Posted-limit expiry preserves an enclosing camera zone.
Saved observations remain available for review/export; they cannot reinstall an
expired runtime limit through the local map index.

End signs use the shared country pictogram in the main sign position for two
seconds after an accepted passage. The new limit takes effect immediately for
fine calculation; the pictogram temporarily replaces its visual circle. The
screen uses the normal fine-based background, including on unlimited roads.

## Map and recognition corrections

- Parse numeric speed tags strictly, including explicit units. Compound,
  conditional and malformed values are not concatenated into a number.
- Resolve country-specific symbolic limits and statutory passenger-car defaults
  consistently for normal map lookup and restriction ends. French defaults use
  130 on motorways, 50 in towns and 80 on ordinary rural roads. A trunk or ramp
  class alone does not establish a carriageway-specific limit. Rain, probationary
  licences and locally posted exceptions are not inferred from this dataset.
  [French official rules](https://www.service-public.gouv.fr/particuliers/vosdroits/F19460).
- Preserve all source road vertices instead of imposing a 24-point budget.
  Release a previous road once its geometry is outside the GPS uncertainty
  allowance. Preserve an aligned current road when a nearby service road's
  distance advantage is within that uncertainty.
- Recognize directed French EB10/EB20 town-boundary evidence during bundle
  generation. Built-up land use and absence of mapped built-up areas are marked
  **low-confidence estimates**, not confirmed legal town boundaries. Only strong
  boundary evidence expires a correction through the map town-transition path.
- Index directed motorway exits up to 350 m beyond each mainline endpoint,
  traversing intervening motorway way splits. Incoming entrance ramps,
  disconnected roads and unresolved one-way directions are excluded. Clients
  include these approaches in the existing narrow exit ambiguity guard. This
  does not claim visual recognition of an arrow or definitive lane assignment.
- Permit an unconditional town/end sign seen in one stable-context frame at
  confidence 0.75 or higher to arm passage detection. Three successfully analyzed
  negative frames are still required. Ordinary single-frame numeric signs keep
  the stricter 0.97 threshold; repeated sightings use the same 0.72 accumulated
  support rule on both clients.
- Include regional coverage polygons on both platforms. Only the newest locally
  installed version of a region participates in routing; old downloads remain
  available for rollback.

Build each region with the pinned requirements in
`scripts/map/requirements-settlement.txt`, the standard artifact packer, then:

```sh
python scripts/map/build_spatialite_v3.py \
  --v1-dist mapdata/dist/REGION \
  --out-db mapdata/dist-v3/REGION/speeds_v3.sqlite \
  --input-pbf REGION-260922.osm.pbf \
  --build-settlement-context --country-code FR \
  --build-way-links --way-links-schema detailed --corridor-mode none
```

The normal country workflow now supplies country metadata, includes French
settlement context, and avoids incomplete incremental updates for French bundles.
The exit approach table is generated by the database builder automatically.

  The external real-release download test is excluded from this local run after
  an interrupted network transfer; deterministic download/checksum tests pass.
- 340 Android unit tests, zero failures; debug APK builds successfully.
- 45 map-pipeline tests and six subtests pass, including directed French town
  signs, complete road geometry, weak settlement evidence, and exit connectivity.

  checksums and sizes were independently verified after packaging.
- Replay of 8,029 recorded GPS fixes with the production iPhone M7 matcher fixes
  the two inspected service-road/stale-reference mismatches. The Languedoc-only
  replay supplies a map speed for 996 of 1,297 previously blank matched samples.
  This count includes points outside that region and is not a legal accuracy score.

  withholds the problematic A9 exit 90s while preserving the sampled mainline
  110s. Images were unavailable for parts of the drive, so those passages do not
  provide independently reviewed ground truth for every speed limit.

Private drive logs, images and replay output are deliberately not included here.
