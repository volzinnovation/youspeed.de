Both device inventories confirm the new versions. The updates replaced the
existing applications in place; neither application was uninstalled or had its
data cleared. Saved preferences and active-map pointer bytes compare equal
before installation, after installation and after normal launch on both phones.
The iPhone's 17 original GPS/matcher/TSR log files remain present with no size
reductions against the morning inventory. This is a metadata check, not a new
content-hash verification of those private logs.

Both normal dashboards were inspected after startup. The iPhone was viewed
through QuickTime's attached-iPhone screen preview without recording. Its
existing log-retention prompt was dismissed on the phone before the dashboard
check. Android's **Logs behalten und fortfahren** action was selected during
verification. The QuickTime preview was closed afterward.

All 39 selected native checks pass on the physical Moto in the separate
`de.youspeed.android.testhost` installation: 12 journal, 16 trip acceptance,
two history, one dashboard, one stop UI, one native share, one conditional OCR
controller and five conditional-camera checks. They include the German stop
control in both orientations and the preserved initial zero. The normal
Android application was installed and relaunched after those checks.

The preceding source verification remains applicable: 190 iPhone native tests
passed with one optional private-fixture skip, plus the stop/odometer simulator
UI test; Android passed 275 JVM and 39 emulator checks. No new physical iPhone
XCTest batch or road drive was run during this deployment. New road recognition
therefore still needs field validation.
