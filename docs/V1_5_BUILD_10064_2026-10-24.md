## Upcoming German town-entry limit

Both readers previously stopped at a settlement boundary and only offered
explicit numeric speed stations. They now derive 50 km/h from a unique accepted,
directed DE:310 entry rule already present in the installed bundle. A valid
same-station explicit limit wins; conditional/lane/direction ambiguity is
withheld. DE:311 remains a boundary, rather than inventing an outside default.
The existing preview UI and map schema are unchanged.

## Unresolved iPhone log-retention discrepancy

All nine old GPS/matcher/TSR files were present by metadata after app/map
installation and before the first launch. After the prompt, the old eight
session files were missing and GPS was 8,096 bytes. The owner confirmed the Keep
action. The agent only viewed QuickTime and supplied no phone touch inputs.
There is no retained trace backup from which to reconstruct these files.

The signed executable's Keep path matches the source preservation code. A new
isolated UI regression seeded synthetic GPS, matcher and a 100,000,001-byte TSR
file, tapped Keep, and independently checked all original SHA-256 hashes after
the UI test. It passed on iOS 18.6 and iOS 26.5 with the phone's landscape
configuration; every synthetic byte survived. This does not reproduce or explain
the physical phone's outcome. No production fix or successful recovery is
claimed. The installed app and conditional map checks are complete; this
retention discrepancy remains open.
