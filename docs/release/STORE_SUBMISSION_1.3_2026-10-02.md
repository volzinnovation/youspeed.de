# YouSpeed 1.3 submission preparation — 2 October 2026

The local release package updates both listings to show dashcam recording, on-device camera traffic-sign recognition, hundreds of country-specific sign classes, offline maps and advisories for Germany, France, Switzerland, Belgium and the Netherlands. Camera recognition is described as a standard feature, as directed by the product owner.

**Prepared locally; not submitted.** Source version is **1.3 (10031)** on both platforms. The iPhone distribution IPA is signed and verified. The Android preparation bundle is unsigned because the existing upload-key environment is absent. Authenticated console operations remain blocked by Computer Use. Neither country availability nor remote metadata has been changed.

## Concrete remaining submission work

1. **Authenticated consoles:** the tool still returns `Computer Use was not approved to use Safari`; Chrome has also returned the same app-denial class despite the user's authorization. The inventory sees both running apps but no Chrome browser session. The cause cannot be established or repaired through the available tools. No console save/upload was attempted through another control mechanism. Once access works, inspect existing versions/tracks, confirm unused 10031, stage the reviewed listing assets and add France, Switzerland, Belgium and the Netherlands while preserving existing countries.
2. **Android upload signing:** configure the existing matching upload key with the four `YOUSPEED_ANDROID_RELEASE_*` variables documented in the Android report; verify its certificate against Play Console, build/sign locally, verify the JAR signature and retain its hash. No replacement key was created.
3. **Android native compatibility:** all 12 packaged 64-bit libraries have aligned LOAD segments and bundle packaging requests 16 KB, but nine libraries fail the additional RELRO end-alignment check. The emulator used for preparation has 4 KB pages. Compatible provider builds and a real 16 KB runtime check remain necessary; cached CameraX/LiteRT updates inspected during preparation did not close the finding. See the exact libraries and remedies in Android readiness. Current [Android guidance](https://developer.android.com/guide/practices/page-sizes) states a 1 February 2027 release restriction; this app's Console warning remains uninspected.
4. **Privacy and public pages:** the [public instance audit](PANORAMAX_PRIVACY_READINESS_2026-10-02.md) resolves operator names, public contribution defaults, licensing and published blur practices. OSM France creates a contributor account on first login; an appropriate account-and-content deletion initiation flow remains unresolved on both platforms. Reconcile remaining retention, recipient, hosting/research and additional account-field label questions. Publish the revised privacy/support pages only after approval, then verify their live contents before submitting the forms. Local deletion does not remove remote photos or accounts.
5. **Existing model rights/readiness:** the country model registry and prior copyright audit retain calibration, rollout and model-lineage/licence review gates. Swiss map/advisory support is prepared, but Swiss commercial pictogram/model approval is not established by this work. Calling camera recognition a standard feature does not change those technical or rights records. See the existing [copyright audit](../license-audit-2026-09-10/README.md), [Swiss readiness](../TSR_CH_PANORAMAX_READINESS.md) and country examples.
6. **Release acceptance and declarations:** freeze the agreed source and match binary fingerprints; complete physical-device acceptance of camera inference, recording/playback/share/delete, speech, country downloads and upgrade/data retention. Check age rating, privacy, export compliance and any store agreements in the consoles. No physical-device deployment or TestFlight/Play internal-test upload was performed.

The user-supplied 1.0.1 (10003) TestFlight baseline is preserved in the platform reports. Git history alone cannot identify that exact upload; current release notes describe 1.3 behavior without inventing a commit-to-store comparison.
