# YouSpeed 1.3 store handoff

The listings lead with **Drive safely. Driver assistance for every car.** Automatic traffic-sign recognition, speed alerts, penalty estimates and dashcam recording support the road-safety purpose. The car's age does not matter because the app needs no vehicle integration. Camera recognition is presented as a standard feature, with country/model availability explained. The release preparation retains source version **1.3 (10032)**. The signed iPhone binary has uploaded to Apple; Android upload signing is still pending.

Apple locales: German, English, French and Dutch. Android locales: those four plus Spanish, Italian, Polish, Brazilian Portuguese and Swedish. French and Dutch localization serve the named countries; Switzerland also has German coverage. Preserve existing store territories and add France, Switzerland, Belgium and the Netherlands using `country-availability-1.3.json` as a proposed configuration.

The galleries pair benefit headlines with complete native interfaces rendered using deterministic demonstration inputs. The app captures are proportionally scaled, with every original retained in `artwork/raw-screenshots/` and hashes in `artwork/screenshot-layouts.json`. Their dashcam preview is empty in the simulator/emulator; generated road photography is used only in the Android feature graphic. Shared traffic-sign artwork is unchanged. Editable copy is in `artwork/marketing-copy.json`; feature-graphic SVGs and backdrop provenance are in `artwork/source/`.

The five country classifiers total **820 country-specific output classes**, of which **469** are display-eligible model classes. These counts include evaluation packs and do not mean 820 unique, reliable live detections. The listings therefore use “hundreds of traffic-sign classes” with an availability qualification. The count and matching iPhone/Android mappings are recorded in `artwork/marketing-evidence.json`. No comparative field benchmark supports “better than most built-in systems”; the copy uses the concrete benefit “You don't need a new car to add driver assistance.”

Search priorities are traffic sign recognition / Verkehrszeichenerkennung, speed limits / Tempolimit, and dashcam; driver assistance, speed alerts, penalty estimates and offline maps support those core intents. The exact recognition phrases appear in Apple keywords and Play short descriptions, as well as descriptions and recognition captions. `artwork/keyword-strategy.json` records English/German variants, long-tail phrases, placements and primary-source research. Priorities reflect feature relevance and user intent, not measured search volumes. Apple keyword fields are localized for all four locales and remain within the repository's conservative 100-byte check. The safety slogan leads the creative; feature terms support discovery without a keyword block in the description.

Render feature graphics with `node scripts/release/generate_store_graphics.mjs` and galleries with `node scripts/release/generate_store_screenshot_layouts.mjs`. Both require Node and Sharp; `YOUSPEED_SHARP_MODULE` can point to a bundled Sharp installation. Capture scripts accept `STORE_SCREENSHOT_NODE` and reapply layouts after native recapture. The layout renderer normally uses retained originals; `--capture-source` adopts fresh native captures, while recognizing already composed files to prevent nested frames. Use `apple` or `android` and `--locales=en-US,de-DE` to limit rendering.

See [the submission dossier](../docs/release/STORE_SUBMISSION_1.3_2026-10-02.md) for binaries, checks and outstanding requirements. `apple/privacy/app_privacy.md` and `android/data-safety/` are evidence-based form drafts with explicitly pending answers; they are not submitted declarations. The included Web privacy/support files are local revisions awaiting publication.

Validate with `python3 scripts/release/validate_store_package.py` from the repository root. Build a review ZIP with `python3 scripts/release/package_store_submission.py`. Neither command contacts a store or submits an app. The ZIP excludes app binaries, credentials, device recordings and debug logs. Source and historical-audit links in the reports refer to the full repository; the ZIP is a listing handoff, not a standalone app source checkout.
