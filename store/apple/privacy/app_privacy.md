# Apple App Privacy Draft

Use this as the source checklist for App Store Connect privacy answers.

## Data Not Used For Tracking

YouSpeed does not use third-party advertising, tracking SDKs, or data brokers.

## Data Used For App Functionality

- Precise Location: used on device to compare current speed and road position with local speed-limit map data.
- Audio Data: microphone input is used only for local spoken speed-limit capture.
- User Content: optional local observations and exported OSM proposal packages can contain user-provided speed-limit corrections.
- Diagnostics: optional local logs can contain precise coordinates and matcher diagnostics when the user explicitly shares them.

## Collection And Sharing

- Routine driving data remains on device.
- Download requests to public release asset hosts may expose standard network metadata such as IP address to that host.
- Local observation exports are only shared when the user chooses to export or share them.
- No data is linked for advertising or tracking.
